📈 Resistance Detection in Pine Script (v6)
This Pine Script v6 script automatically detects resistance levels by identifying local highs over a defined period. It filters out closely positioned resistance levels to avoid redundancy and dynamically plots them on the chart as horizontal lines.

🔍 Features
Identifies resistance levels based on local highs.
Filters out nearby levels to prevent duplication.
Dynamically plots resistance levels on the chart.
Adjustable parameters:
Analysis period (length): Defines the window for detecting local highs.
Deviation (%) (deviation): Prevents displaying excessively close resistance levels.
📌 Usage
Copy the code into Pine Script on TradingView.
Adjust the parameters as needed.
Apply the script to a chart to visualize resistance levels.
🛠️ Parameters
Parameter	Description	Default Value
length	Analysis period for detecting local highs	20
deviation	Tolerance to avoid redundant levels (%)	1.5
